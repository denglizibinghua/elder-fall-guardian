# 功能描述 — 基于树莓派+毫米波雷达的老人跌倒监护原型

## 1. 项目名称
基于树莓派+毫米波雷达的老人跌倒监护原型（边缘计算）

## 2. 一句话
LD2450轨迹雷达看人在哪、LD2450静止+MPU6050尖峰融合判摔没摔（60MI01已封存不用），DHT11/MPU6050/MAX30102采环境和体征，超阈值或跌倒时本地网页横幅+大按键求助+落盘，树莓派边缘端独立判断不断网可用。

## 3. 功能
1. 存在+轨迹：LD2450实时坐标，有人/无人、活动量
2. 跌倒报警：MPU尖峰后N秒静止确认，网页横幅+落盘+尝试拍照（摄像头缺席时跳过）
3. 环境体征：DHT11温湿度、MPU6050活动/步态、MAX30102心率血氧（有指夹时）
4. 一键求助：红色大按键按下即报警（GPIO17，三脚有源VCC接3V3，空闲LOW/按下HIGH，逻辑已取反，已验证落盘）
5. Web看板：连笔记本热点<你的热点SSID>，浏览器开<树莓派IP>:8080看实时状态、轨迹、报警记录
6. 向下分层（L2）：派判断→STM32/舵机执行待接，当前执行仅报警拍照链；断网本地照样报警落盘

## 4. 硬件（全现货，零采购）
派4B + LD2450（在用）+ LD2410（在流）+ DHT11 + MAX30102 + MPU6050 + 大按键 + CSI摄像头（detected=0，可选）；60MI01封存

## 5. 验收
人走过显示存在，挥手坐标跟手，模拟跌倒（蹲下慢起/躺）触发报警弹网页，按按键报警（PRESSED+落盘），关热点重演一次本地照样报警落盘（重开后补刷验证）。
