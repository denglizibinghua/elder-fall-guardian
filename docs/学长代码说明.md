## main.py（450行，总控，systemd开机自启）
- 引脚：按键GPIO17，DHT11用board.D5=GPIO5，MPU6050用硬I2C bus1地址0x68，LD2410的OUT接GPIO6
- 线程：SharedState全局状态 + 4个worker（mpu计步/ld2410存在/ld2450轨迹/max30102心率血氧）+ sensor_loop拍照上传
- 上传：旧<旧服务器地址，已失效>（手机热点时代残留，已死）仍在代码中轮询但均带超时保命；演示走本地status.json/alarms.jsonl+:8080，不受影响；清URL是可选卫生项
- 实测：能跑，雷达/心率线程都起，DHT数据流正常（既往GPIO5警告不影响读数）
