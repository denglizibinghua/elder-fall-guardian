# 云端部署记录 · 2026-10-24（脱敏版）

> 「老人跌倒监护」项目云端部分：MQTT broker + 数据留档 + 外网看板。
> 部署于既有生产服务器（与另一业务共存：独立库 / 独立站点 / 独立端口，互不影响）。
> 本文件为**脱敏版**——不含凭据、公网地址与真实域名。资产样例见 `cloud/`。

## 1. 设计目标与红线

- 云端只做：**数据留档 + 外网查看**；不参与实时判定（断网时边缘端本地照常判定/报警/落盘）。
- 与既有生产共存：**全部新建**（新库 / 新目录 / 新 server 块 / 新 systemd 服务），不动任何现有业务。
- 资源预算 ≤250MB 内存（实测新增 ~65MB，无 Docker/JVM 类重组件）。

## 2. 拓扑

```
[树莓派] edge_bus ──MQTT over TLS :8883──▶ [云 mosquitto]
                                              ├─▶ MySQL（报警事件 + 状态降频）
                                              └─▶ /opt/elder-ui/（板端同格式文件）
                                                        │
                                          [云端 UI（板端 app.py 原样部署）]
                                                        │
                                          [nginx：HTTPS 主入口 + :8080 备用，WS 直通]
```

## 3. 组件

| 组件 | 说明 |
|---|---|
| mosquitto | TLS :8883；独立账号 + ACL（板端只能写自己 topic）；禁匿名 |
| elder-bridge | 订阅 `elder/v1/#` → MySQL 留档 + 生成看板文件（源码见 `cloud/elder-bridge.py`） |
| elder-ui | 板端 `app.py` 原样部署（仅改监听端口；需补 `ws.py`） |
| nginx | HTTPS 主入口（Let's Encrypt）+ :8080 备用；WS 直通；响应 `no-store` |
| MySQL | 独立库：`events`（event_id 唯一）/ `state_samples`（60s 降频） |

## 4. 关键设计

- **板端零代码改动**：仅 systemd 环境变量切云；自签 CA 装入板子系统信任库。
- **节拍**：板端 state 发布 0.5s（演示提速；原始 10s，heartbeat 保持 10s）；云端「数据陈旧」阈值与之匹配。
- **幂等**：`event_id` UNIQUE + `INSERT IGNORE`；仅新事件追加看板文件（防重复显示）。
- **断网降级**：板端 JSONL outbox 落盘 + 恢复自动补发（云端无感）。

## 5. 验证记录

- 外网 HTTPS：Let's Encrypt 证书有效、自动续期；页面 / API / WS 全通。
- **WS 帧级测试**：以原始 socket 读取真实数据帧（不止握手）；wss 握手 101。
- 断云演练：停 broker 45s → 桥接器 30s 标记离线 → 恢复后 ~19s 自动续传。
- 事件去重：同 event_id 发布 2 次 → DB 1 行、看板 1 条。
- 回归：既有生产站点未受影响。

## 6. 回滚（摘要）

- ufw 删 8883；停用并删除 `elder-bridge` / `elder-ui`（unit + 目录）；nginx 删两个 server 文件 + reload；
- MySQL：DROP 独立库（不动其它库）；板子：删 systemd drop-in + daemon-reload + restart → 自动回到本机 broker。
