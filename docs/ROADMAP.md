# 进阶路线 ROADMAP — 每级都可独立交（老人监护方向，2026.09.26 修订）

> 核心思想：L1 混分保底，L2 冲分，L3 看时间。旧二次元管家路线作废。

## L0 环境打通（0.5 天，不算分）
- 派能 SSH（热点+SSH 密钥，IP <树莓派IP>），`main.py` 能跑，LD2450/MPU 存活已验证
- 验收：SSH 上去看到 radar_targets 和 accel 数据在动

## L1 混分版（2-3 天，目标第二层 70-85）
- 功能：LD2450 存在+轨迹 + MPU 计步 + DHT11 温湿度上本地看板 :8080（派系统时钟，status.json的updated_at即证明）
- 融合只留初版：MPU 尖峰后 N 秒静止即报警，写 alarms.jsonl+网页弹窗
- 执行只留 1 个：报警联动拍照+网页横幅（摄像头缺席时拍照跳过）；LED/STM32执行移入L2
- 不碰：60MI01（封存）、摄像头（detected=0 先不管）、语音 LLM/TTS
- 交件：能演示（走过显示存在、模拟跌倒报警落盘+横幅、按键报警；拍照项以落盘+横幅为准）+报告 30% 套模板就能交

## L2 冲分版（再+3 天，目标第三层 80-95）
- 加：派→串口→STM32→舵机/风扇，向下控制分；LD2450+LD2410+DHT11+MPU6050+MAX30102+大按键共6种已超标（无光照传感器，以devices.json为准）
- 算法加固：融合加 N 秒确认窗+10 秒冷却，误报率写进报告当智能算法分
- 看板加曲线：存在时长、活动量、报警历史，同热点浏览器可看
- 验收：手机网页点一下，舵机动一下；断网重演本地照样报警落盘

## L3 完全体（看时间，目标第四层 90-100）

- 人设/多模型可换，RVC 唱歌当彩蛋
