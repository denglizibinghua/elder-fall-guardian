## 3. 相对 board-snapshot-20261021 的差异

10-21 交接后的两轮迭代（下称波一 / 波二），10-24 版为当前运行态。

### 3.1 波一（10-21）：运行时 / 算法 / 总线重构

- **`main.py` 463 行 → 12 行**：拆分为 `edge_runtime.py`（硬件线程 + 主循环）与 `edge_bus.py`（MQTT 总线），入口只保留 `run()` 调用。
- **判定换代**：`fall_fusion.FallDetector`（纯 transition）→ `smart_fusion.SmartFallDetector`（transition 硬门槛 + 7 特征 Logistic 评分）：
  - 特征：`speed_peak_3s / drop_slope / still_duration / still_variance / track_quality / presence / imu_delta`；
  - 模型外置 `model.json`（阈值 0.60，权重/归一化可热调）；评分不足记 `SUPPRESSED` 不落盘。
- **报警 schema 扩展**：在 `time/type/detail` 基础上新增 `event_id / correlation_key / device_id / confidence / model_version / evidence / photo_ref`（旧字段保留，向后兼容）。
- **MQTT 总线**：topic 结构 `elder/v1/<room_id>/<device_id>/<kind>`（heartbeat / state / event / command / ack），QoS1、
  retained 心跳、LWT 离线告示、JSONL outbox 断线补发；`MQTT_HOST/PORT/TLS/USER/PASSWORD` 环境变量预留云端切换。
- **看板实时化**：app.py 增加 `GET /ws`（WebSocket 推送 status/alarms/nodes）+ `GET /api/health`，页面 WS 优先、失败退回轮询。
- **实测效果**：采集主进程 CPU 由 ~100% 降至个位数（系统负载 <0.5）。

### 3.2 波二（10-24）：Premium Sentinel 前端 + 服务端增强

- **新增 `index.html`**（42.5KB 单页）：深色医疗风，6 工作区（总览/轨迹/报警/设备/相册/说明），手机 320/390px 与桌面宽屏两套布局。
- **app.py**：新增 `POST /api/ack`（报警确认 → `acknowledged.jsonl` 持久化）、`GET /api/nodes`（节点在线状态）、
  照片 `valid/size` 字段、CSV 控制字符清洗、`/api/health` 扩展 `transport/outbox` 字段。
- **部署**：`food-web.service` → `webapp.service`（单元文件随快照收录）。

## 5. 已知边界与未验证项

10-21 的三条物理边界继续成立：单平面雷达无高度通道（坐下/跌倒同构）、桌载 MPU 冲击证据不可用、单目标追踪架构。

本轮新增/遗留（**不应作为验收结论**）：

- 2 小时连续稳定性、按键硬件→页面确认全链路、断网/重启恢复演练、连续重复报警合并效果——均未做长期验证。
- **报警去重**：`correlation_key` 已在事件中生成（10s 分桶），代码中暂未见消费 / 合并逻辑。
