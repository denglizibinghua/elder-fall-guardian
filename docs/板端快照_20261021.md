## 4. 恢复/部署到一台新板子

```bash
# 1) 代码
scp main.py fall_fusion.py rules.json app.py devices.json admin@<PI>:/home/admin/food_project/
# 2) 服务
sudo cp deploy/food_project.service deploy/food-web.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now food_project food-web
# 3) 依赖
pip3 install RPi.GPIO smbus2 adafruit-circuitpython-dht paho-mqtt pyserial   # 或 apt 对应包
# 4) 可选：本机 MQTT 总线
sudo systemctl enable --now mosquitto   # 只监听 127.0.0.1 即可，无外部依赖
```
